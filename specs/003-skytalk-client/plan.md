## Summary

The SkyTalk client is a React 18 single-page application built with Vite and
TypeScript. It communicates with the SkyTalk server exclusively through tRPC hooks —
`@trpc/react-query` wraps the `chatStream` subscription and `sendQuery` mutation,
providing fully typed request/response shapes inferred from the server's `AppRouter`.
The client renders a persistent chat thread and drives the product's defining UX:
dynamic weather themes and CSS-animated atmospheric elements. All animations are pure
CSS with zero JS bundle impact.

## Technical Context

**Language/Version**: TypeScript 5.x, React 18, Node.js 20 LTS (dev tooling only)
**Primary Dependencies**:

- `vite` — build tool and dev server (scaffolded with `pnpm create vite -- --template react-ts`)
- `react` + `react-dom` — UI framework
- `@trpc/client` — tRPC client core; creates typed procedure callers
- `@trpc/react-query` — React hooks wrapping tRPC procedures
- `@tanstack/react-query` — peer dependency; query/mutation/subscription state management
- No CSS framework (plain CSS + CSS custom properties)
- No animation library (pure CSS `@keyframes`)

**Type Contract**:

```typescript
// src/lib/trpc.ts
import { createTRPCReact } from '@trpc/react-query';
import type { AppRouter } from '../../../server/src/router';
export const trpc = createTRPCReact<AppRouter>();
```

The `import type` is erased at compile time — no runtime dependency on server code.

**Dev Dependencies**:

- `vitest` — test runner (Vite-native)
- `@testing-library/react` + `@testing-library/user-event` — component testing
- `jsdom` — DOM environment for Vitest
- `msw` (Mock Service Worker) — intercept tRPC HTTP calls in tests

**Storage**: None — React state + TanStack Query cache only; no localStorage in v1
**Testing**: Vitest + React Testing Library; tRPC procedures mocked via MSW
**Target Platform**: Modern desktop browsers (Chrome, Firefox, Safari)
**Project Type**: Single-page web application
**Performance Goals**: Loading animation visible within 100ms of submit (SC-C-001);
CSS animations at 60fps (SC-C-003); 0KB animation JS bundle overhead (SC-C-004)
**Constraints**: Pure CSS animations only; no external UI component library;
`VITE_SERVER_URL` env var required; `AppRouter` type import from server source
**Scale/Scope**: Single user per browser session; demo/interview scale

### tRPC Provider Setup

`App.tsx` MUST wrap the component tree with both `QueryClientProvider` and
`trpc.Provider` before any hooks can be used:

```typescript
// App.tsx
const queryClient = new QueryClient();
const trpcClient = trpc.createClient({
  links: [
    splitLink({
      condition: (op) => op.type === 'subscription',
      true: wsLink({ client: createWSClient({ url: import.meta.env.VITE_SERVER_WS_URL }) }),
      false: httpBatchLink({ url: import.meta.env.VITE_SERVER_URL }),
    }),
  ],
});
```

### CSS Theme Architecture

Four named themes drive all visual variation. Theme is applied via a `data-theme`
attribute on `<html>`, toggled by `useWeatherTheme`:

```css
[data-theme="neutral"] { --bg-primary: #e8eaf0; --accent: #607d8b; }
[data-theme="sunny"]   { --bg-primary: #fff8e1; --accent: #f9a825; }
[data-theme="cloudy"]  { --bg-primary: #eceff1; --accent: #78909c; }
[data-theme="rainy"]   { --bg-primary: #e3f2fd; --accent: #1565c0; }
[data-theme="stormy"]  { --bg-primary: #1a237e; --accent: #7c4dff; }

html { transition: background-color 0.8s ease, color 0.4s ease; }
```

### Decorative Element Strategy

| Theme | Element | Keyframe |
|-------|---------|---------|
| sunny | `.sun` div | `pulse` (scale + opacity) |
| cloudy | `.cloud` divs (2–3) | `drift` (translateX) |
| rainy | `.raindrop` spans | `fall` (translateY, staggered) |
| stormy | `.cloud-dark` + `.bolt` | `drift` + `flicker` |

All use `transform` and `opacity` only — no layout-triggering properties.
